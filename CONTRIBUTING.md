# Contributing

This repository is a preserved bachelor's research release. Issues and reproducibility corrections are welcome, but continued hardware access or active maintenance is not guaranteed.

Before proposing a change:

1. Run the portable tests and publication-integrity check in the README.
2. Keep physical-flight commands disabled and use isolated SITL for mission work.
3. Never edit retained experimental records to make a result pass. Add a new version, protocol, raw bundle and interpretation instead.
4. Keep source-code changes separate from new scientific claims. A passing unit test does not establish an accuracy improvement or operational reliability.
5. Do not upload credentials, device snapshots, personal records, dataset media or model binaries without an explicit rights and privacy review.

Software contributions must be compatible with AGPL-3.0-only. The document/media rights notice remains separate. Numerical changes require new provenance and a deliberate update of the publication manifest.
