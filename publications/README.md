# Final publications

This folder intentionally contains one final thesis and one final seven-minute defense, rather than the revision history.

- `Jahanimajd_Thesis.pdf`: 118-page defended thesis, final terminology-consistent local PDF.
- `Jahanimajd_Defense.pdf`: ten visible main slides, static compatibility version.
- `Jahanimajd_Defense.pptx`: editable presentation with embedded hardware/mission GIFs, speaker notes and eight hidden examiner-reference slides.

PowerPoint slideshow mode is needed for GIF playback. The PDF cannot animate. Hidden appendix slides are available for questions and are not part of the timed main talk. The speaking budget was 6:45; actual delivery requires rehearsal.

The preserved files match their approved source hashes in `evidence/publication_manifest.json`. Personal preparation PDFs, review correspondence and old versions are not included.
