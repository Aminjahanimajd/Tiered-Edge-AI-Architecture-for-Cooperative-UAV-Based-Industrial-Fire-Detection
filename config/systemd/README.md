# Device-specific service examples

These are reviewed configuration examples, not automatically installed services. The public copies replace the historical laptop recipient with loopback through `GCS_HOST=127.0.0.1`; set an authorized endpoint explicitly for your own bench setup. No hotspot password or device credential is included.

MAVProxy must be installed separately. The historical copied implementation is not vendored. Verify its executable path and CLI version. The camera example requires the historical NVIDIA GStreamer plugins and correct V4L2 camera format. Starting these services can open a serial device or camera and transmit telemetry/video; do not enable them blindly.

These examples are not byte-identical experiment configuration evidence. Measured services and their original configuration/hash boundaries are described in the dated reports.
